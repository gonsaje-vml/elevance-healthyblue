Elevance Health EDS Migration

Tracking the migration of Elevance Health provider and member sites to Adobe Edge Delivery Services (EDS), authored through Document Authoring (DA). This page summarizes where the project stands, recent work, the current sprint scope, and the block library available for building pages.

Where things stand In progress

The Elevance EDS project is set up and ready for content migration. It uses two Document Authoring sites — elevance and elevance-nc — served from a single GitHub repository (shared blocks, styles, and scripts). The content mounts, block library, and page-import tooling are all in place. The first page migration — the GRS provider home page (on elevance) — is planned and in progress. No pages are published to the live environments yet.

Shared repository

Repo GitHub repository github.com/AdobeDrago/elevance One repo for both sites: blocks, styles, scripts, and this docs page.

Status. Both sites are bot-protected during setup and share one block library (the AEM Block Collection baseline). Current DA mapping: elevance → GRS provider (provider.bluemedadvgrhs.com/grs-provider) and elevance-nc → Healthy Blue NC provider (provider.healthybluenc.com/north-carolina-provider). Other source sites are not yet assigned to a DA site. Per-page migrations reuse existing blocks first, adding styling variants as new page types are brought over. Header/navigation is deferred on the first import pass.
